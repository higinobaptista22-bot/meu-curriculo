## Tecnologias e recursos demonstrados
- **HTML5 semântico:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure` e `figcaption`.
- **Multimédia:** `img`, `video` e `audio`, com `alt`, `controls`, `poster` e `source`.
- **Formulário HTML5:** `required`, `pattern`, `min`, `max`, `minlength`, `maxlength`, `accept`, `fieldset` e `legend`.
- **CSS:** variáveis em `:root`, Flexbox, CSS Grid, seletores avançados, pseudo-classes, pseudo-elementos, transições, `@keyframes`, gradientes, sombras e unidades relativas.
- **Responsividade:** abordagem mobile-first com breakpoints até 768px e 480px.
